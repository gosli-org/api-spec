# API Spec

Shared JSON contract between the TypeScript client and Go server, authored in TypeSpec. Provides TypeScript declarations, Go structs with JSON tags and OpenAPI. Generated artifacts are committed alongside their source.

The package supplies types and an OpenAPI schema; consumers own HTTP handling and runtime validation. It exports no JavaScript runtime code.

## Use in a TypeScript client

Install this repository as a local dependency:

```sh
npm install /absolute/path/to/api-spec
```

```ts
import type { components } from "api-spec";

type Request = components["schemas"]["Client.Request"];
const request: Request = {
  id: crypto.randomUUID(),
  type: "listProjects",
  token: "example-token",
};
const body = JSON.stringify(request);
```

TypeScript declarations check code at compile time. Runtime validation belongs to the consuming application.

## Use in a Go server

Add to the consumer's `go.mod`, adjusting the local path:

```go
require api-spec v0.0.0
replace api-spec => ../api-spec
```

```go
import (
    "crypto/rand"
    "encoding/json"
    apispec "api-spec/Go"
)

// Inside a function:
id := rand.Text()
request := apispec.ClientRequest{Id: id, Type: apispec.ListProjects, Token: "example-token"}
body, err := json.Marshal(request)
```

Request IDs are strings generated by the sender; UUID strings are one option. The contract does not enforce ID uniqueness. Request types are `listProjects`, `createSession` and `attachSession`.

Go JSON decoding does not enforce required fields or enum membership; validate incoming data in the server. The module name `api-spec` supports local use; publishing a Go module requires a repository import path and updated consumer imports. The npm package is private.

## Change the contract

Requires Node.js 22.18+ (24 recommended), npm 11+ and Go 1.25+. Generators are installed through the package managers; no global generator installation is needed.

```sh
npm ci
# Edit src/main.tsp, then regenerate and check:
npm run generate
npm run check
```

Edit [`src/main.tsp`](src/main.tsp), then commit the source and regenerated artifacts together. Generated files are overwritten during generation; make changes in TypeSpec or generator configuration.

`npm run check` checks TypeScript declarations and compiles the Go package. The first generation may download Go tool dependencies.

Run `npm run watch` to generate once and regenerate OpenAPI, TypeScript and Go whenever a `.tsp` file under `src/` changes. Keep it running while editing; stop with Ctrl+C. Generation errors are reported, and watching continues. Run `npm run check` separately to check the result.

Before changing the model or generation pipeline, read the [architecture and contract rules](ARCHITECTURE.md).
